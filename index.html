Tentang saya

Lulusan Sistem Informasi yang tertarik mengembangkan solusi digital berdasarkan kebutuhan pengguna.

Saya merupakan lulusan S1 Sistem Informasi Universitas Multi Data Palembang (MDP) tahun 2026. Selama kuliah, saya mengerjakan proyek pengembangan sistem informasi dan mempelajari pengembangan aplikasi web, aplikasi mobile, serta pengelolaan basis data.

Saya memiliki pengalaman kerja praktik di PT Telkomsel Regional Sumbagsel dalam pengembangan dashboard monitoring sales dan aplikasi pencatatan event sales. Saat ini, saya juga mengajar Informatika dan Coding di SD IT Kamiliyah Palembang. Saya siap terus belajar, bekerja sama dalam tim, dan berkontribusi melalui pengetahuan serta keterampilan yang saya miliki.
